Support

Need help with Swarmline? Most answers are below. Still stuck? Email {{SUPPORT_EMAIL}} or open an issue on GitHub.

Getting started

  1. Install Swarmline from the Chrome Web Store, then pin it from the puzzle-piece menu next to the address bar.
  2. Open any website and click the Swarmline icon (or press Alt + Shift + L).
  3. Watch, tour, finish: Auto-tour is on by default and T toggles it, F shows the finished page, H hides or shows the controls, Esc exits. Drag the control bar to move it; double-click it to put it back.

Common questions

The icon shows a red × and nothing happens

Chrome doesn't let any extension run on its own pages (chrome:// pages, the Chrome Web Store) or inside the built-in PDF viewer. Open a normal website and try again.

How do I record a video of it?

Use any screen recorder (Windows: Win + Alt + R, or the Snipping Tool's record mode; macOS: Shift + Cmd + 5). Start Swarmline (Auto-tour is already on), press H to hide the controls (or drag them to a corner), and pick 2× for a snappy reel or 1× for a calm walkthrough. Press H again to bring the controls back.

Can I click the page while it's being built?

Not while it's building, so you can't hit a link you can't see yet. You can still scroll, and the swarm builds whatever comes to rest on screen. As soon as it finishes (or you press Finish), the page is fully interactive.

Does it change or save the website?

No. Swarmline only hides and re-shows parts of the page in your own browser tab for the animation. Nothing is saved, nothing is sent anywhere, and when it ends or you exit, the page is exactly as it was. Reloading the page also clears it completely.

Some part of a page didn't animate, it just appeared

Decorative backgrounds and very small details come in with the end-of-screen sweep rather than being built one by one, and content you scroll past quickly simply appears. On very large pages (thousands of elements), the far end is built in bigger pieces.

The shortcut doesn't work

Another extension may already use Alt + Shift + L. Open chrome://extensions/shortcuts and set a different one for Swarmline.

Can I make it calmer or faster?

Use the 1× / 2× / 3× button in the toolbar at the bottom. If your system is set to reduce motion, Swarmline automatically uses a smaller swarm and a quicker build.
